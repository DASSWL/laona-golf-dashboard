数据说明

数据从哪来

YouTube Data API v3 的公开数据：频道信息、上传列表、每支视频的统计、播放列表和评论。播放、点赞、评论都是截至抓取时的累计值，新视频还在涨。这是第三方整理的看板，不是 YouTube 或频道官方页面。

标准杆和杆数

标准杆 = 同一格式（长视频或 Shorts）此前 10 支视频的播放中位数。播放是标准杆的 2 倍以上记老鹰，1.25–2 倍小鸟，0.8–1.25 倍标准杆，0.5–0.8 倍柏忌，0.5 倍以下双柏忌。每种格式的第一支视频没有标准杆。

内容支柱怎么分

教学：教学、新手入门、规则、健身、明星挥杆分析。新闻赛事：每月新闻、新闻、比赛介绍、人物介绍。装备测评：装备和品牌、开箱测评。旅行 Vlog：下场打球、旅行、球场介绍。升学和娱乐（搞笑、技巧秀）各自成类。不在任何播放列表里的记为未分类。

观众洞察和建议

评论主题、观众请求、标题模式、数据发现和建议由 Claude 分析数据和评论后写成，又经过一轮重新计算数字、一轮挑推理毛病的复核。它们是判断，不是 YouTube 给出的数字。
