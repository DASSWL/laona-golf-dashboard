# 老那高尔夫频道仪表盘

A dashboard for the YouTube channel [老那高尔夫 Lao Na Golf](https://www.youtube.com/@laonagolf), built from public YouTube Data API v3 data. It is a third-party page, not an official channel or YouTube page.

Live site: https://dasswl.github.io/laona-golf-dashboard/

## Refresh the data

1. Put your key in `.env` at the repo root (git-ignored): `YOUTUBE_API_KEY=...`
2. Start the local refresh service: `python3 tools/refresh_server.py`
3. Open the site once with `?owner=1` so this browser shows the 「刷新数据」 button. Click it whenever you want fresh numbers.

The button pulls fresh data on this computer (`tools/fetch_channel.py` → `tools/build_site_data.py`), commits `data/channel.json`, `data/videos.json` and `data/comments.json`, pushes, and returns once GitHub Pages serves the new data. The analysis files (`data/advice.json`, `data/findings.json` …) were written from the 2026-10-15 data and are not regenerated by a refresh.
